## 🩺 نبذة عن المنصة والرسالة

تبدأ رحلة العلاج الحقيقية لمرضى الأمراض المزمنة وكبار السن في منازلهم بعيداً عن أعين الأطباء والصيادلة. تكمن الفجوة في فقدان منظومة الاستشعار بعد الخروج، مما يؤدي إلى عدم التزام المريض، تضارب الأدوية وتعددها (Polypharmacy)، ومضاعفات سريرية حرجة تنتهي بزيارات طوارئ مكلفة وتنويم متكرر يمكن تفاديه.

منصة **عافية كير (AafiyaCare)** صُممت كمنظومة ذكاء سريري استباقي ترصد الإشارات السلوكية والدوائية والحيوية، وتحللها عبر محرك مخاطر تنبؤي لتصعيد التدخلات السريرية الوقائية للصيادلة والأطباء في التجمعات الصحية قبل حدوث الانتكاسة.

> **شعارنا الراسخ:** «نكتشف الخطر قبل أن يصبح أزمة — Detect Risk. Intervene Early. Improve Outcomes.»

## 🎯 المشكلة السريرية والقيمة المقترحة

### المحاور الأربعة للمخاطر الدوائية التي تعالجها المنصة:
1. **سلامة العلاج (Medication Safety):** كشف التعارضات والتفاعلات الدوائية والتكرارات العلاجية الخاطئة فوراً.
2. **الالتزام الدوائي (Medication Adherence):** تتبع نمط الاستخدام الفعلي والانتظام في أخذ الجرعات بموعدها بدقة.
3. **استمرارية الرعاية (Medication Continuity):** سد فجوة الانقطاع بعد الخروج من المستشفى وتسهيل إعادة الصرف الدوري.
4. **ترشيد الهدر (Medication Waste):** حصر الأدوية الفائضة أو المتروكة وتقليص النفقات غير المستغلة على المنظومة الصحية.

## ⚙️ محركات المنصة التقنية الأربعة (Core Engines)

```
┌────────────────────────────────────────────────────────────────────────┐
│                      منصة عافية كير (AAFIYACARE)                       │
├─────────────────────┬─────────────────────┬────────────────────────────┤
│ 1. جواز الدواء      │ 2. محرك السلامة     │ 3. محرك المخاطر التنبؤي    │
│    الرقمي الذكي     │    الدوائية         │    (Predictive Risk)       │
│  Medication Passport│   Safety Engine     │    Machine Learning Engine │
│ ─────────────────── │ ─────────────────── │ ────────────────────────── │
│ • مسح الرؤية بكاميرا│ • تدقيق التعارضات   │ • خوارزميات المخاطر        │
│   الهاتف (CV)       │   المتعددة للوصفات  │   التراكمية (0-100)        │
│ • تسجيل الجرعة بنقرة│ • فلاتر Beers       │ • فرز الأولوية السريرية    │
│   واحدة وتعزيز إيجابي│ • ترشيد التنبيهات   │ • التنبؤ باحتمال الانتكاسة │
├─────────────────────┴─────────────────────┴────────────────────────────┤
│ 4. لوحة التحكم السريرية لفرق التجمعات الصحية (Clinical Intelligence)   │
│ • فرز المراجعين • إدارة التدخلات بنموذج SBAR • تحليلات الالتزام والهدر  │
└────────────────────────────────────────────────────────────────────────┘
```

1. **جواز الدواء الرقمي الذكي (Medication Passport):**  
   ملف دوائي موحد ومحدث بالوقت الفعلي يربط المريض بالمنشأة الصحية، مدعوم بتقنيات الرؤية الحاسوبية (Computer Vision) للتعرف الفوري على علب الأدوية والوصفات بكاميرا الهاتف لمنع أخطاء الإدخال، مع واجهة مبسطة لكبار السن لتسجيل الجرعة بنقرة واحدة وتعزيز سلوكي إيجابي ودعم صوتي.

2. **محرك السلامة الدوائية (Safety Engine):**  
   تدقيق فوري في تركيبة الأدوية لرصد التعارضات الخطيرة، والازدواجية العلاجية، والجرعات الخاطئة، مع خوارزميات ذكية لتنقية الإنذارات الهامشية وتفادي إرهاق التنبيهات (Alert Fatigue).

3. **محرك المخاطر التنبؤي (Predictive Risk Engine):**  
   بناء نماذج تعلم آلي لتوقع احتمالية الانتكاسة أو الانقطاع عن العلاج أو حدوث هدر دوائي، وتصنيف ديناميكي للمرضى وفق مصفوفة خطورة ذكية لفرز وتوجيه أولويات التدخل السريري بناءً على المخاطر المتراكمة.

4. **لوحة التحكم السريرية الذكية (Clinical Intelligence Dashboard):**  
   واجهة مركزية لقيادات التجمعات الصحية وفرق الصيدلة السريرية والرعاية الممتدة لمتابعة أداء المنظومة، وتقارير فورية حول معدلات السلامة والالتزام ومؤشرات الهدر ونسب نجاح التدخلات لدعم القرارات المستندة للبيانات.

## 🔄 مسار العمل الرباعي المغلق (Closed-Loop Workflow)

تعمل المنصة وفق حلقة مغلقة ذكية ومتصلة لحماية المريض في كل مرحلة:

```
[ 1. الالتقاط (Detect) ]
   └── تتبع إشارات تفاعل المريض، مسار الرعاية، ومواعيد صرف الأدوية.
        ▼
[ 2. التنبؤ بالخطر (Predict) ]
   └── تشغيل خوارزميات الذكاء الاصطناعي لحساب درجة الخطر التراكمي (Composite Risk Score).
        ▼
[ 3. التدخل السريري (Intervene) ]
   └── إشعار فوري للصيدلي السريري أو الطبيب المعالج عبر خطة تدخل SBAR محكمة.
        ▼
[ 4. القياس والتحسين (Measure) ]
   └── قياس استقرار الحالة، توثيق نجاح التدخل، وتغذية خوارزميات التعلم الآلي راجعياً.
```

## 📊 مؤشر النجم الشمالي ومؤشرات الأداء (KPIs)

> **مؤشر النجم الشمالي للمنصة (North Star Metric):**  
> **«عدد الحالات عالية الخطورة التي تم رصدها وحلها بنجاح قبل حدوث انتكاسة طبية»**

| المؤشر الأساسي (KPI) | طريقة الحساب والمستهدف السريري | الأثر المباشر المحقق |
| :--- | :--- | :--- |
| **دقة الإشارة السريرية (Signal Precision)** | نسبة التنبيهات السريرية الصائبة والمفيدة سريرياً **> 85%** | تقليل إرهاق التنبيهات (Alert Fatigue) وكسب ثقة الكوادر الطبية. |
| **معدل قبول التدخل (Intervention Rate)** | اعتماد الكادر الطبي لـ **> 80%** من توصيات التدخل الاستباقية | ترجمة الرؤى البرمجية إلى إجراءات علاجية منقذة ومباشرة. |
| **تجنب التكاليف (Cost Avoidance)** | خفض تكاليف إعادة التنويم وزيارات الطوارئ بنسبة **20% - 30%** | عائد استثماري مالي مباشر للتجمعات الصحية وشركات التأمين. |
| **خفض الهدر الدوائي (Waste Reduction)** | حصر وإعادة تنظيم صرف الأدوية وتقليل الهدر بنسبة **25%** | ترشيد ميزانيات الدواء واستدامة الموارد الطبية. |
| **سرعة الاستجابة (MTTI / MTTR)** | اكتشاف الخطر في **أقل من 24 ساعة** والتدخل خلال **48 ساعة** | منع تدهور الحالة الصحية للمريض في المهد. |

## 🛡️ درجات تصنيف المخاطر ومبدأ «الإنسان في الحلقة» (HITL)

> **المبدأ السريري والأخلاقي الصارم:**  
> الذكاء الاصطناعي في عافية كير **لا يتخذ قرارات علاجية مستقلة ولا يعدل الوصفات تلقائياً**، بل يقتصر دوره على الفرز الذكي والتنبؤ الاستباقي، بينما يبقى القرار السريري النهائي بيد الصيدلي الإكلينيكي أو الطبيب المعالج (**Human-in-the-Loop**).

```
   ┌─────────────────────────────────────────────────────────────┐
   │ 🔴 أولوية عالية (High Priority)                             │
   │    زمن الاستجابة: خلال 12 - 24 ساعة                         │
   │    الإجراء: تدخل سريري فوري عبر اتصال هاتفي أو مراجعة عاجلة │
   ├─────────────────────────────────────────────────────────────┤
   │ 🟠 خطر متصاعد (Rising Risk)                                 │
   │    زمن الاستجابة: خلال 48 - 72 ساعة                         │
   │    الإجراء: مراجعة استباقية للملف، إرشادات وجدولة استشارة   │
   ├─────────────────────────────────────────────────────────────┤
   │ 🟡 مراقبة مستمرة (Continuous Monitor)                       │
```

## 🚀 تشغيل المشروع محلياً (Quick Start)

### المتطلبات الأساسية:
- **Node.js** (إصدار 20.x أو أحدث)
- **npm** أو **pnpm**
- مفتاح Google Gemini API (اختياري للذكاء الاصطناعي التوليدي عبر المتغير `GEMINI_API_KEY`)

### خطوات التثبيت والتشغيل:

```bash
# 1. استنساخ المستودع
git clone https://github.com/your-username/aafiya-care-platform.git

# 2. الدخول إلى مجلد المشروع
cd aafiya-care-platform

# 3. تثبيت الاعتماديات البرمجية
npm install

# 4. إعداد متغيرات البيئة (اختياري للربط مع Gemini API)
cp .env.example .env
# أضف مفتاحك الخاص: GEMINI_API_KEY=your_key_here

# 5. تشغيل السيرفر في بيئة التطوير
npm run dev
```

افتح المتصفح وتوجه إلى الرابط: `http://localhost:3000`
